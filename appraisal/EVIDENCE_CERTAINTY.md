# EVIDENCE CERTAINTY — 證據確定性分級

維護者：dapa-methods-auditor；稽核日 2026-08-27；對象 main @ b7322d4。
分級方法：GRADE 精神之四級（高／中／低／極低），起點依研究設計，依偏誤風險、
不精確、不一致、間接性（含藥物→類別外推）、發表偏誤調降；大效應可調升。
**每一格的「確定性」指向括號內之特定主張，不是整個領域。**

---

## 1. 第 2 型糖尿病心血管預防

| 主張 | 確定性 | 理由 |
|---|---|---|
| dapagliflozin 降低 T2D 之 HHF（HR 0.73, 0.61–0.88） | **高** | 大型雙盲 RCT 主要端點成分；類別統合一致（0.77 類別） |
| dapagliflozin 未證明降低 MACE（0.93, 0.84–1.03） | **高**（對「無顯著效果」之確定性） | 17,160 人、4.2 年、事件充足之信賴區間窄；非劣性成立 |
| MACE 效益限於已確立 ASCVD | **低** | class-level 統合之次族群，p-int 0.0501 邊際；藥物間接性 |
| DECLARE 腎保護（0.76；renal-specific 0.53） | **中** | prespecified secondary；正式檢定地位待全文確認（ENDPOINT_AUDIT §7.1）；事件數少之成分（ESRD/renal death 11 vs 27）另降為低 |
| 預防新發 T2DM（DAPA-MI 前期糖尿病 HR 0.74, 0.55–0.99） | **低** | post hoc 次分析、邊際顯著、代謝端點 |

## 3. 慢性腎臟病

| 主張 | 確定性 | 理由 |
|---|---|---|
| 蛋白尿 CKD（eGFR 25–75＋UACR 200–5000）：主要複合 0.61、all-cause death 0.69 | **高** | 雙盲 RCT、大效應、早期中止（潛在高估效應之小幅保留不足以降級） |
| 有無 T2D 效益一致 | **中→高** | prespecified subgroup，p-int 0.24；非 T2D 層 n 較小 |
| eGFR <30（stage 4）有效 | **低** | subgroup、CI 跨 null（27%, −2 至 47）；僅「與整體一致」 |
| eGFR 20–25 起始 | **低** | 無 dapagliflozin RCT；EMPA-KIDNEY 類別外推（間接性）＋指引背書 |
| 非蛋白尿 CKD（UACR <200） | **低** | DAPA-CKD 未納入；KDIGO 2B；類別＋pooled 外推 |
| 類別腎病進展保護（SMART-C RR 0.63） | **高**（類別主張） | 13 試驗 90,409 人一致；引用時限類別語言 |
| 起始後 eGFR dip 可逆、不預示不良結局 | **中** | post hoc／secondary 分析（Adamson、Jongs）＋指引一致背書 |

## 7. 進階 CKD／透析／移植／ADPKD

| 主張 | 確定性 | 理由 |
|---|---|---|
| 透析病人硬結局效益 | ——無證據 | DARE-ESKD-2 為中性 surrogate 試驗（n=80/24 週）；PK 良好僅支持可行性 |

## 8. 安全性主張

| 主張 | 確定性 | 理由 |
|---|---|---|
| T2D 長期使用 DKA 風險倍增、絕對風險 <0.5%/4 年 | **高** | RCT 裁定事件（HR 2.18 待 NEJM 全文核，%與 P 已自摘要核）＋大型觀察性一致（CNODES 2.85） |
| 非糖尿病使用者 DKA 極罕見但非零 | **中**（罕見）＋case-signal（非零） | RCT 非糖尿病層零事件（DAPA-HF/DAPA-CKD prespecified 已全文核）；個案報告證實可發生 |
| 生殖器黴菌感染顯著增加 | **高** | 仿單 pool＋RCT＋meta 一致（女 8.4 vs 1.5% 等） |
| 嚴重 UTI 不增加 | **中** | RCT secondary＋觀察性一致；HR 待全文核 |
| Fournier 壞疽為真實但無法定率之訊號 | 訊號層級 | FAERS 無分母；試驗中個位數事件 |
| 無截肢／骨折超額（dapagliflozin 專屬） | **中→高** | DECLARE 裁定截肢（Bonaca 已核）＋meta 一致；骨折 meta 有一離群（Sridharan vs Admani）須並陳 |
| 不增加 AKI（趨向減少） | **中**（dapa）／**高**（類別 RR 0.77） | DECLARE HR 0.69 之件數印刷矛盾待全文核；registry 與類別 meta 方向一致 |
| 單用不增加重度低血糖 | **高** | 多試驗一致（DAPA-HF/DAPA-CKD 已全文核；DECLARE HR 待核） |
| 起始後 2 週 eGFR dip 約 3–4 mL/min、可逆 | **中** | post hoc／prespecified 分析一致；指引背書 |
| 症狀性低血壓於急性期起始略增（3.6 vs 2.2%） | **中** | RCT 安全端點（已核）；未達之正式檢定不明 |
| 術前停藥 3 天可消除圍術期 DKA 風險 | ——反向 | 無比較性證據；停藥 5–11 天後仍有 euDKA／糖尿之個案（case-signal）；仿單自承糖尿可持續 2 週。所有停藥時程均為「風險降低」共識，非實證最適值 |
| 圍術期 DKA 發生率 0.17%／1.1% | 不可引用 | 一手來源未核實（安全檔已標）；維持禁用 |

## 使用規則

1. synthesis/talk 中每一效益主張須可回溯到本表一列；若找不到對應列，
   先回報 Director 補審，不得自行升級。
2. 「高確定性」不等於「大效益」：DECLARE HHF 為高確定性小絕對效益
   （ENDPOINT_AUDIT §8 之 NNT 表）。
3. 「——未證明／反向／無證據」列為紅線：出現在投影片上時只能以
   「目前無證據／試驗未顯示」語態呈現。
